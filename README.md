# Резюме и портфолио — Алексей Тимко

Персональная страница-резюме Android-разработчика (Kotlin).

## Возможности
- Адаптивная верстка (мобильные устройства, планшеты, десктоп).
- Автоматическая поддержка темной и светлой тем системы (`prefers-color-scheme`).
- Кнопка **«Распечатать / Сохранить в PDF»** с настроенным `@media print` (убирает лишние интерфейсные элементы, формирует компактный PDF).
- Прямые ссылки на репозитории GitHub (`Borshchevyk`, `Market`, `AE:Health`, `KubMarket`) и контакты (Telegram, Email).

## Инструкция по публикации на GitHub Pages

1. Создайте на GitHub новый публичный репозиторий с точным именем:
   ```
   de4ltt.github.io
   ```
2. В терминале в папке `C:\Users\Honor\de4ltt.github.io` выполните:
   ```bash
   git remote add origin https://github.com/de4ltt/de4ltt.github.io.git
   git push -u origin main
   ```
3. Через 1–2 минуты ваше резюме будет доступно по адресу:
   **https://de4ltt.github.io**
